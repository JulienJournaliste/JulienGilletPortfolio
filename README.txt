# Julien Gillet — site

## Structure

- `index.html` : toute la page
- `style.css` : design + responsive
- `images/` : tes images

## Images à ajouter

Place tes fichiers dans `images/` avec ces noms (ou modifie les noms dans `index.html`) :

### Mammouth media
- puericultrice.jpg
- ukraine.jpg
- velos.jpg
- jonathan.jpg
- parlement.jpg
- el-nino.jpg
- armeniens.jpg

### Enquête d'un toit
- fonds-logement.jpg
- enquete-toit.jpg

## Liens

Dans `index.html`, remplace :

- LIEN_ARTICLE_1 à LIEN_ARTICLE_7
- LIEN_ENQUETE_1
- LIEN_ENQUETE_2

par les URL réelles.

Les cartes sont entièrement cliquables et ouvrent les liens externes dans un nouvel onglet.

## Tester sur Mac

Double-clique sur `index.html` pour l'ouvrir dans ton navigateur.

Aucun serveur ou WordPress n'est nécessaire pour tester cette version.
